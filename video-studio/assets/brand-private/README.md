# Recursos privados de Un Dato Más

Estos son recursos de marca del usuario para reutilizar en producciones de **Un Dato Más**. Se mantienen localmente en el proyecto y Git los ignora mediante `.gitignore`.

- `logo.png`: icono/logo cuadrado de la marca, copiado del recurso fuente del usuario.
- `profile-background.png`: fondo/banner de perfil de la marca, copiado del recurso fuente del usuario.
