# 📁 Mis Temas de Videos (video-studio/mis-temas/)

Este directorio almacena los cuestionarios estructurados de definición de video cuando se trabaja fuera del entorno de **Antigravity IDE** (por ejemplo, en Cursor, VS Code, Claude Code o interfaces web) donde no se dispone de modales interactivos o artefactos nativos.

## 📝 Uso del Cuestionario

1. El asistente genera un archivo `cuestionario-[tema-o-fecha].md` en esta carpeta.
2. Abre el archivo y completa:
   - **¿De qué va a tratar el video?** (escribe tu idea central).
   - **Giro y enfoque:** selecciona con una `[x]` el tono (científico con humor, educativo, dramático, misterio, etc.).
   - **Formato:** selecciona con una `[x]` (`9:16`, `16:9` o ambos).
   - **Duración:** selecciona con una `[x]`.
   - **Motor de Voz:** selecciona con una `[x]` (ElevenLabs, VibeVoice, TTS nativo).
   - **Logo animado:** selecciona con una `[x]` si se incluye o no el logo final.
3. Guarda el archivo y notifica al asistente para que inicie la producción automática.
