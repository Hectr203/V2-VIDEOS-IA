# 💡 Mis Ideas e Historias (`video-studio/mis-ideas/`)

Esta carpeta almacena **automáticamente** todas las ideas, bancos de temas, fórmulas de contenido e historias generadas por cualquier agente, *skill* o asistente del proyecto.

> **Privacidad:** Todo archivo personal generado aquí está excluido en `.gitignore` (solo se versionan este `README.md` y `.gitkeep`) para que tus ideas privadas nunca se suban a repositorios compartidos.

---

## Convención obligatoria de nomenclatura

Todo archivo guardado aquí debe seguir estrictamente este formato:

```text
[DD de mes de YYYY] - [Categoría] - Nombre del tema.md
```

### Ejemplos válidos
- `[23 de noviembre de 2026] - [Mejores ideas para publicar] - Perros y comportamiento.md`
- `[23 de noviembre de 2026] - [Mejores ideas para expandir mi audiencia] - Formula ganadora Un Dato Mas IG.md`
- `[23 de noviembre de 2026] - [Tendencias del nicho] - Curiosidades cientificas virales.md`
- `[23 de noviembre de 2026] - [Historias y guiones en borrador] - La historia real de Laika.md`

---

## Categorías recomendadas

| Categoría | Cuándo usarla |
| :--- | :--- |
| `Mejores ideas para publicar` | Ideas validadas listas para el calendario editorial inmediato. |
| `Mejores ideas para expandir mi audiencia` | Ideas de amplio atractivo (*Broad Appeal*), alto potencial de envíos por DM y crecimiento de nuevos seguidores. |
| `Ideas para fidelizar comunidad` | Temas diseñados para disparar comentarios, debates, nostalgia y series recurrentes. |
| `Tendencias del nicho` | Oportunidades detectadas mediante investigación web activa (`niche-research` / `yt-viral`). |
| `Historias y guiones en borrador` | Premisas narrativas, arcos de historia y ganchos antes de pasar a `video-studio/mis-temas/` o `storyboard.json`. |
