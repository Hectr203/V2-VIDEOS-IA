# VOXSTAGE 视觉系统

默认使用这一统一视觉参考，除非用户明确指定其他风格。

- **THE STAGE：** 低饱和档案地图与陈旧纸张纹理构成空置、平坦、均匀打光的持久 16:9 舞台；不预置中景元素，所有剪纸与数据卡在其上进出。
- **色彩：** 仅用档案纸棕 `#C9BB9C`、油墨黑 `#1A1A1A`、网点灰 `#8C8C8C`、炽热红 `#D62E1F`、芥末黄 `#D9A441`。红色限于错位描边、下划线、箭头及数据卡；芥末黄只作少量次级强调。
- **组件：** 黑白半调人物剪纸配粗粝白边和轻微错位红色套印；撕裂纸、红色数据卡、定位标记、红色手绘线、细白边档案照片卡均为实体哑光纸张，带纸纤维、印刷颗粒、撕裂边与柔和层影。
- **动效：** 人物入场带轻微过冲回弹；数字逐格跳动；下划线从左至右绘制；镜头最多约 2% 慢速漂移。优先纸张滑入、压贴、盖章和撕纸，禁止流体、橡胶和光滑 CGI 变形。
- **禁令：** 禁止光亮 CG、三维塑料质感、镜头光晕、渐变、水印、无关标志、随机乱码和非必要可读文字。
