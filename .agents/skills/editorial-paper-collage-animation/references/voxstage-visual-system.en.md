# VOXSTAGE Visual System

Use this system by default unless the user explicitly specifies another style.

- **THE STAGE:** an empty, flat, evenly lit 16:9 world of desaturated archival map and aged-paper texture; do not pre-place midground objects. All cut-outs and data cards enter and exit this stage.
- **Color:** use only Archival Tan `#C9BB9C`, Ink Black `#1A1A1A`, Halftone Gray `#8C8C8C`, Hot Red `#D62E1F`, and Mustard `#D9A441`. Restrict red to registration offsets, underlines, arrows, and data cards; use mustard sparingly as a secondary accent.
- **Components:** black-and-white halftone figure cut-outs carry a rough white border and subtly offset red registration. Torn paper, red data cards, map pins, red hand-drawn lines, and thin-white-border photo cards remain matte physical paper with fibers, print grain, torn edges, and soft layered shadows.
- **Motion:** figures enter with a slight overshoot and settle; numbers tick in steps; underlines draw left to right; camera drift never exceeds roughly 2%. Prefer sliding paper, pressing tape, stamping, and tearing. Forbid fluid, rubbery, or glossy CGI motion.
- **Prohibitions:** no glossy CG, plastic 3D, lens flare, gradients, watermarks, unrelated logos, random glyphs, or unnecessary readable text.
