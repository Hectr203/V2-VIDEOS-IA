# Remotion Agent Skills (remotion-dev/skills)

Suite oficial de habilidades para agentes de IA de Remotion (`npx skills add remotion-dev/skills`).

Para conocer los principios técnicos de renderizado, JSX y animación, consulta la [Guía de Habilidades Remotion](GUIA-REMOTION-DEV-SKILLS.md).

## Habilidades incluidas
- `remotion-best-practices`: Router maestro y directrices generales de Remotion.
- `remotion-markup`: Mejores prácticas de markup, JSX, interpolaciones y transformaciones.
- `remotion-captions`: Animación, transcripción y visualización de subtítulos.
- `remotion-studio`: Previsualización interactiva con Remotion Studio.
- `remotion-render`: Exportación y renderizado de video en Remotion.
- `remotion-create`: Scaffolding y layout de composiciones.
- `remotion-interactivity`: Creación de timelines y componentes con interactividad.
- `remotion-maps`: Animaciones cartográficas vectoriales y 3D.
- `remotion-multimedia`: Utilidades multimedia con Mediabunny.
- `remotion-docs`: Búsqueda de documentación de Remotion.
- `remotion-saas`: Patrones para aplicaciones y servicios de video en la nube.
- `remotion-upgrade`: Guía para actualización de paquetes de Remotion.
