# Narrative character system

Use one named character per story. Reuse the same hair silhouette, facial marks, clothing palette, and head-to-body proportion across poses. Keep black ink lines at one dominant weight, use only one muted clothing color plus a tiny accent, and reserve detailed hatching for clothing or important props.

Build each scene from separate layers: room/background, prop(s), character pose, and story text. Do not bake the character into a one-off background illustration.
