# VOXSTAGE 视觉系统

将本系统作为默认的统一视觉参考；只有用户明确提供另一套风格时才替换。

## 舞台与材质

- 所有画面发生在同一个持久的「THE STAGE」：低饱和档案地图与陈旧纸张纹理形成的空置 16:9 舞台；光线平坦、均匀，画面中不预置中景元素，供人物剪纸、照片卡与数据卡进出。
- 保留哑光档案纸、可见纸纤维、印刷颗粒、黑白半调网点、撕裂边与柔和的层间纸影；气质严肃、冷静、权威，略带复古新闻编辑部感。
- 禁止光亮 CG、3D 塑料质感、镜头光晕、渐变、随机乱码、水印、无关标志及未被允许的可读文字。

## 色彩与排印

仅使用：档案纸棕 `#C9BB9C`、油墨黑 `#1A1A1A`、网点灰 `#8C8C8C`、炽热红 `#D62E1F`、芥末黄 `#D9A441`。红色只用于错位描边、下划线、箭头、数据卡与指示；芥末黄只作少量次级强调。标题采用高瘦、紧凑、粗体大写的编辑标题字；若必须出现文字，只使用用户提供且已核实的精确短标签。

## 组件构造

- 人物：黑白半调照片剪纸，粗粝白色外描边，背后轻微错位的红色套印描边。
- 物件：撕裂纸张、红色大数据计数卡、地图定位标记、红色手绘下划线、细白边档案照片卡、少量芥末黄标签。
- 每个组件都必须遵循同一逻辑：实体纸张分层、黑白半调印刷、白边与错位红色套印跳色；保持编辑网格、统一页边距、充足负空间。

## 动效语言

人物剪纸以轻微过冲回弹弹出；数据计数器逐格上跳；红色下划线从左向右划过；摄影机仅作约 2% 的缓慢漂移。优先纸张滑入、压贴、盖章、撕纸与错位套印等物理纸艺动作，避免流体、橡胶或平滑 CGI 变形。
