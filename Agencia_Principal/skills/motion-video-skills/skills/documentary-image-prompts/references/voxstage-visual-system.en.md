# VOXSTAGE Visual System

Use this system by default unless the user explicitly supplies a replacement style.

## Stage and materials

- Set every shot in the persistent **THE STAGE**: an empty 16:9 field of desaturated archival map and aged-paper texture, evenly pre-lit and free of pre-set midground objects, ready for cut-outs, photo cards, and data cards to enter and exit.
- Preserve matte archive paper, visible fibers, print grain, black-and-white halftone dots, torn edges, and soft inter-layer paper shadows. Keep the mood serious, calm, authoritative, and slightly retro editorial.
- Forbid glossy CG, plastic 3D rendering, lens flares, gradients, random glyphs, watermarks, unrelated logos, and unapproved readable text.

## Color and typography

Use only Archival Tan `#C9BB9C`, Ink Black `#1A1A1A`, Halftone Gray `#8C8C8C`, Hot Red `#D62E1F`, and Mustard `#D9A441`. Reserve red for registration offsets, underlines, arrows, data cards, and indicators; use mustard sparingly as a secondary accent. Use tall, condensed, bold editorial caps for titles. If text is necessary, use only exact short labels verified by the user.

## Component construction

- Figures: black-and-white halftone photo cut-outs with a rough white contour and a subtly offset red registration outline.
- Props: torn paper, large red data counter cards, map pins, hand-drawn red underlines, thin-white-border archival photo cards, and sparse mustard labels.
- Build every component with the same logic: layered physical paper, halftone printing, white edges, and an offset red registration accent; retain an editorial grid, uniform margins, and generous negative space.

## Motion language

Pop figures in with a small overshoot and settle; make data counters tick upward step by step; draw red underlines left to right; limit camera motion to an approximately 2% slow drift. Prefer physical paper slides, presses, stamps, tears, and registration offsets; avoid fluid, rubbery, or smooth CGI deformation.
