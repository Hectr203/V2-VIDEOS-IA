# Style Reference Boards

Inspect the sibling `../assets/` directory before visual work. Default to `mg-voxstage.webp`; switch only when the user explicitly names a board, and never mix systems within one shot.

- `mg-voxstage.webp`: archival paper, black-and-white halftone, hot-red registration, editorial maps, and paper collage; use for documentaries, news, geopolitics, and data stories.
- `mg-soft3d.webp`: creamy soft light, rounded matte soft-3D forms, and simple building-block compositions; use for friendly education and concept explainers.
- `mg-glassdark.webp`: dark glassmorphic UI, neon violet/cyan/blue, glowing data, and spatial haze; use for technology, networks, finance, and systems.
- `mg-blueprint.webp`: deep-blue engineering blueprints, white linework, dimension labels, exploded views, and technical grids; use for engineering, manufacturing, and “how it works” stories.

Use MG-VOXSTAGE when no board is specified. Preserve the selected system's materials, palette, typography, and motion logic; never cross-mix systems.
